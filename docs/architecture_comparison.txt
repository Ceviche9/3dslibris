PROBLEMA #1: Perda de Contexto Entre Páginas
─────────────────────────────────────────────

    <p style="margin-left: 40px">Parágrafo longo que quebra...</p>

    PÁGINA 1 (durante parsing):
    ┌─────────────────────────────────────────┐
    │ EmitFlowedShapedText():                 │
    │   metrics.margin_left = 16 + 40 = 56    │
    │   p->pen.x = 56                         │
    │   Emite: [TEXT_LINE_START_X][56]        │
    │   Emite: [P][a][r][á][g][r][a][f][o]   │
    │   ...altura excedida...                 │
    │   Chama: AdvancePageOnOverflow()        │
    └─────────────────────────────────────────┘

    PÁGINA 2 (continua parsing):
    ┌─────────────────────────────────────────┐
    │ EmitFlowedShapedText():                 │
    │   ❌ Variável metrics.margin_left       │
    │      foi resetada ou perdida!           │
    │   p->pen.x = 16 (base margin)           │
    │   Emite: [l][o][n][g][o][...]           │  ← POSIÇÃO ERRADA!
    │                                         │
    │ Texto cortado/desalinhado na tela!      │
    └─────────────────────────────────────────┘

    SOLUÇÃO ATUAL: Desabilitar TEXT_LINE_START_X completamente
    → Perde funcionalidade de indentação CSS ❌

    • Usuário muda tamanho de fonte 12pt → 16pt

      - Re-executa XML parser
      - Re-calcula tudo

    • Bookmarks apontam para offsets no buffer:
      bookmark.position = 15234  (byte offset em Page.buf[])
      - Se re-parse, offsets mudam!
      - Bookmarks ficam inválidos ❌

SOLUÇÃO #1: Contexto Preservado
────────────────────────────────

    <p style="margin-left: 40px">Parágrafo longo que quebra...</p>

    DocumentTree:
    ┌─────────────────────────────────────┐
    │ ContentNode {                       │
    │   type: BLOCK,                      │
    │   style: { margin_left: 40 },       │  ← PRESERVADO!
    │   text_utf8: "Parágrafo longo..." │
    │ }                                   │
    └─────────────────────────────────────┘


    PÁGINA 1:
    ┌──────────────────────────────────────────┐
    │ LayoutEngine::ComputePage(node, 0)       │
    │                                          │
    │ ctx.block_stack.push({                   │
    │   effective_margin_left: 16 + 40 = 56    │ ← SALVO no stack
    │ });                                      │
    │                                          │
    │ LayoutTextNode():                        │
    │   pen.x = 56                             │
    │   Adiciona fragments em x=56             │
    │   ...página cheia...                     │
    │   page.end_position = {node, offset=80}  │ ← Salva ONDE parou
    └──────────────────────────────────────────┘


    PÁGINA 2:
    ┌──────────────────────────────────────────┐
    │ LayoutEngine::ComputePage(node, 80)      │
    │                                          │
    │ Retoma do MESMO node!                    │
    │ ctx.block_stack.push({                   │
    │   effective_margin_left: 16 + 40 = 56    │ ← RECALCULADO do style!
    │ });                                      │
    │                                          │
    │ LayoutTextNode():                        │
    │   pen.x = 56                             │ ✅ CORRETO!
    │   Continua de offset=80                  │
    └──────────────────────────────────────────┘

    ✅ Margens preservadas!
    ✅ Indentação CSS funciona!

    │   original (não ao buffer)           │
    │                                      │
    │ ✅ Sobrevive a mudanças de layout!   │
